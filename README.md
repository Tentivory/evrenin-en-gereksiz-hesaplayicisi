# Evrenin En Gereksiz Hesaplayıcısı

Bu repository, insanlığın en büyük sorularından birine cevap arar: **"Hiçbir şey hesaplamasak ne olur?"**

## Ne Yapar?

Hiçbir şey. Ama bunu çok ciddi yapar.

- Rastgele "gereksiz" sayılar üretir.
- Onları sonsuza kadar toplar.
- Sonucu asla vermez.
- Beklemenizi ister.

## Kurulum

```bash
git clone https://github.com/Tentivory/evrenin-en-gereksiz-hesaplayicisi.git
cd evrenin-en-gereksiz-hesaplayicisi
python3 hesaplayici.py
```

## Kullanım

Sadece çalıştırın. Çıkmak için Ctrl+C. Çıkamayabilirsiniz. Bu bir özelliktir.

## Felsefe

Beklemek, hesaplamanın en yüksek formudur. Bu program, beklemenin matematiksel ifadesidir.

## Katkı

Katkıda bulunmayın. Gereksizdir.
